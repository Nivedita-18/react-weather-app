# 🌦 Weather App

A modern and responsive Weather App built with React and Vite that provides real-time weather updates using the OpenWeather API.

## ✨ Features

- 🔍 Search weather by city
- 📍 Get weather using current location
- 🌡️ Real-time temperature and weather conditions
- 🕒 Hourly weather forecast
- 📅 5-Day weather forecast
- 🌫️ Air Quality Index (AQI)
- ⭐ Favorite cities
- 🕘 Recent searches
- 🌙 Light/Dark mode
- 🎨 Dynamic weather backgrounds
- 📱 Fully responsive design
- ⚠️ Error handling and loading states

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- CSS3
- OpenWeather API

## 🚀 Getting Started

```bash
npm install
npm run dev
```
